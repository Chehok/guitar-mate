기타메이트 사용 가이드

기타 줄을 맞추는 것부터 악보의 코드를 바꾸는 것까지, 다섯 가지 예시로 따라 해보세요.

튜닝

표준 튜닝은 가장 굵은 6번 줄부터 E–A–D–G–B–E입니다. 기본은 자동이라 아무 줄이나 튕기면 가장 가까운 줄을 찾아 맞춰줘요.

  1. 마이크 켜기를 누르고 브라우저에서 마이크 사용을 허용합니다.
  2. 프렛을 누르지 않은 채 한 줄만 튕깁니다. 헤드 그림에서 주황 테두리로 표시된 줄이 지금 인식한 줄입니다.
  3. 게이지가 왼쪽이면 음이 낮고, 오른쪽이면 높습니다. 줄감개를 조금씩 돌리고 다시 튕겨 바늘을 가운데(0 센트)에 맞춥니다.
  4. 줄이 많이 풀려 다른 줄로 인식되면 헤드 그림에서 그 줄을 직접 누르세요. 그 줄에 맞추고 기준음도 들려줘요. 다시 자동으로 하려면 자동 스위치를 켜세요.

※ 작은 소리가 잡히지 않으면 마이크 감도를 높이고, 주변 소음이 잡히면 낮추세요. 마이크를 쓰기 어렵다면 줄을 눌러 기준음을 듣고 귀로 맞출 수 있어요. 마이크 소리는 기기 안에서만 분석하며 녹음하거나 전송하지 않습니다.

코드 검색

사용 예시 · Cmaj7 운지 읽기
악보에 Cmaj7이 나오면 코드 이름을 그대로 검색해 손가락 위치와 구성음을 확인할 수 있습니다.

  1. 코드 이름으로 찾기에 Cmaj7을 입력하고 코드 찾기를 누릅니다. Bb, F#m11, C/G, C7(b9,b13)처럼 복잡한 이름도 입력할 수 있어요.
  2. 다이어그램은 왼쪽부터 6번 줄입니다. O는 프렛을 누르지 않고 치는 줄, X는 치지 않는 줄입니다.
  3. 예를 들어 6번부터 X–3–2–0–0–0으로 표시된 운지는 5번 줄 3프렛과 4번 줄 2프렛을 누르고, 3·2·1번 줄은 그대로 칩니다.
  4. ← 이전과 다음 →으로 같은 코드의 다른 운지를 보고, 소리 듣기로 연주한 음과 비교합니다.

※ 이름이 기억나지 않으면 위쪽 토글을 필터로 바꾸고 기본음을 골라 보세요. 그 기본음의 코드가 한 줄로 나오니 옆으로 넘기며 고르고, 아래 근음 줄에서 C/G 같은 슬래시 베이스도 고를 수 있어요. 아래 지판에서 찾기에는 0–15프렛 전체에서 근음과 구성음 위치가 표시되고, 지금 보고 있는 운지는 진한 색으로 보여요.

코드 판별

영상에서 본 손 모양이나 내가 연습한 운지가 무슨 코드인지 확인할 때 쓰는 기능입니다. 화면의 기타 지판에 어느 줄을 몇 프렛에서 누르는지 직접 표시하면, 그 운지에서 나는 음을 계산해 가능한 코드 이름을 보여줍니다.

사용 예시 · 5번 줄과 4번 줄의 2프렛만 눌렀을 때

1 / 4
1. 5번 줄 2프렛 누르기

지판에서 5번 줄 · 2프렛 칸을 손가락으로 누르면 점이 찍혀요. 같은 칸을 다시 누르면 지워져요.

2. 4번 줄 2프렛 누르기

이어서 4번 줄 · 2프렛도 눌러요. Em 운지에서 손가락으로 누르는 곳은 이 두 칸뿐이에요.

3. 치는 줄의 X를 O로 바꾸기

줄 위의 X를 누르면 O(개방현)로 바뀌어요. 6번 줄과 3·2·1번 줄을 모두 O로 바꿔요. 점을 찍은 줄은 —로 표시되니 그대로 두면 돼요.

4. 코드 후보 확인하기

여섯 줄에서 E·G·B 세 음이 나서 코드 후보에 Em이 맨 앞에 나와요. 후보를 누르면 코드 검색으로 넘어가요.

  1. 시작 프렛을 1로 두고, 5번 줄과 4번 줄의 2프렛 칸을 각각 누릅니다. 같은 칸을 다시 누르면 점이 지워져요.
  2. 6번 줄과 3·2·1번 줄 위의 X를 눌러 O로 바꿉니다. X로 두면 그 줄은 판별에서 빠집니다.
  3. 이대로 여섯 줄을 치면 E·G·B 세 음이 납니다. 화면의 코드 후보에 Em(이 마이너)이 표시됩니다.

※ 최저음이 근음인 해석과 생략음이 적은 후보가 앞에 나오고, 후보를 누르면 코드 검색으로 넘어갑니다. 높은 포지션은 시작 프렛을 올려서 표시하고, 소리 듣기로 운지 소리를 확인하거나 초기화로 처음부터 다시 할 수 있어요.

메트로놈

4/4박자 메트로놈이에요. 템포는 40~240 BPM에서 슬라이더나 숫자 입력으로 조절하고, 첫 박은 조금 더 강하게 들려요.

사용 예시 · 60 BPM에 맞춰 스트로크 연습하기

  1. 템포 숫자에 60을 입력하거나 슬라이더를 움직여 60 BPM으로 맞추고 시작을 누르세요.
  2. 진자가 가운데를 지나며 클릭음이 날 때마다 기타 줄을 한 번씩 쳐보세요. 1–4 박 표시가 차례로 켜지고, 첫 박은 더 강하게 들려요.
  3. 박자가 익숙해지면 BPM을 조금씩 올려보세요. 연습을 마치면 멈추기를 누르세요.

※ 소리가 나지 않으면 기기의 무음 모드와 브라우저 음량을 확인해 주세요.

사용 예시 · 여러 폰을 같은 박자로 맞추기

합주하거나 여럿이 함께 연습할 때는 메트로놈 싱크를 쓰세요. 한 사람(리더)의 메트로놈에 다른 폰들이 맞춰 울려요.

1 / 4
1. 리더 폰에서 방 만들기

리더가 될 폰에서 메트로놈 싱크의 리더로 방 만들기를 누르면 숫자 4자리 방 코드와 QR이 나와요.

2. 다른 폰은 방 코드로 참여

다른 폰은 방 코드로 참여에 숫자 4자리를 넣고 참여하기를 눌러요. 리더 화면의 QR을 카메라로 찍어 열었다면 맨 위의 참여하기를 누르면 돼요.

3. 리더가 시작하면 모두 같은 박에

리더가 시작을 누르면 모든 폰이 같은 박에 울려요. 리더가 멈추거나 템포를 바꾸면 다른 폰도 함께 따라가요.

4. 어긋나게 들리면 내 소리 타이밍 맞추기

내 소리가 다른 폰보다 늦게 들리면 +5·+20(빠르게), 일찍 들리면 −5·−20(느리게)을 눌러요. 참여한 폰은 리더 폰 가까이에서 자동 맞추기를 누르면 마이크로 6초 동안 듣고 알아서 맞춰요. 리더가 시작하기 전에 눌러 두면 시작할 때까지 기다렸다가 들어요.

※ 메트로놈 싱크는 인터넷 연결이 필요해요. 블루투스 이어폰은 소리가 늦게 나서 빠르게 쪽으로 많이 옮겨야 할 수 있고, 맞춘 값은 그 기기에 저장돼요.

※ 다른 앱으로 넘어가면 소리가 멈춰요. 돌아와서 다시 듣기를 누르면 같은 방에서 이어서 들려요.

악보 키 변환

악보 속 코드가 어려워 카포를 끼우고 싶을 때.
키가 너무 높아서 한 키만 내리고 싶을 때.
악보 사진을 넣으면 연주하기 편한 코드로 바꿔줘요!

지판에서 카포 위치를 고르면 원래 키에 맞는 코드 모양으로 바뀝니다. +를 누르면 카포가 올라가며 코드 모양의 키가 내려가고, −를 누르면 올라가요. 카포 없음에서 −를 누르면 카포 없이 키를 올려요.

  1. 악보 선택이나 클립보드에서 붙여넣기로 악보 이미지(JPG·PNG, 최대 20MB)를 불러오거나 업로드 영역에 끌어 놓습니다. 코드는 자동으로 인식되며, 이미지는 기기 안에서만 처리돼요. 첫 자동 인식에는 인터넷 연결이 필요합니다. 다른 악보로 바꾸려면 미리보기 위의 다른 악보을 누르세요.
  2. 감지 키를 확인하고, 잘못 읽힌 코드가 있으면 악보에서 그 코드를 눌러 수정합니다. 아래 악보 코드 · 확인 및 수정 목록에서도 고칠 수 있어요.
  3. 악보 아래 지판에서 2프렛을 누르거나, 카포 없음에서 +를 두 번 누릅니다. 악보에 표시된 새 코드 모양을 확인하고, 실제 기타에도 카포를 2프렛에 끼운 뒤 연주합니다. 카포 줄의 코드 재생을 누르면 바뀐 코드를 악보 순서대로 한 마디씩 들어볼 수 있어요(템포·박자는 추천 전주 설정을 따라요).
  4. 코드가 인식되지 않았다면 코드 직접 추가를 누르고, 악보에서 빠진 위치를 선택한 뒤 원래 코드 이름을 입력해 저장합니다. 추가한 코드는 끌어서 위치를 옮길 수 있습니다.
  5. 악보 왼쪽 위에는 키가 작게 표시돼요(예: C폼 (Capo 2) / D키). 필요 없으면 악보 위의 키 표시를 끄세요.
  6. 추천 전주에서 쉬운 전주, 곡의 첫 코드 진행, 곡 끝 코드 진행을 활용한 전주를 템포·박자를 골라 들어보고, 악보에 넣기로 키 표시 아래에 넣습니다. 넣은 전주는 끌어서 옮기고, 눌러서 연 팝업의 악보 속 전주 크기로 크기를 바꾸거나 악보에서 빼기로 지울 수 있어요.
  7. 다 됐으면 PNG 다운로드로 저장합니다.

※ 원래 코드가 D–A–Bm–G일 때, 카포를 2프렛으로 설정하면 C–G–Am–F가 표시됩니다. 교체는 원래 코드를 가리고 새 코드를 쓰고, 위에는 원래 코드 위에 새 코드를 씁니다. 사진처럼 배경이 복잡한 악보는 위에가 깔끔해요. 원본으로 언제든 원래 악보와 비교할 수 있고, 악보와 수정 내용은 새로고침하면 초기화됩니다.
