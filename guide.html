기타메이트 사용 가이드

기타 줄을 맞추는 것부터 악보의 코드를 바꾸는 것까지, 다섯 가지 예시로 따라 해보세요.

튜닝

표준 튜닝은 가장 굵은 6번 줄부터 E–A–D–G–B–E입니다.

  1. 마이크 켜기를 누르고 브라우저에서 마이크 사용을 허용합니다.
  2. 튜닝할 줄에서 6번 줄을 선택하고, 프렛을 누르지 않은 채 그 줄만 튕깁니다.
  3. 게이지가 왼쪽이면 음이 낮고, 오른쪽이면 높습니다. 줄감개를 조금씩 돌리고 다시 튕겨 바늘을 가운데에 맞춥니다.

※ 마이크를 쓰기 어렵다면 기준음 듣기로 비교할 수 있습니다.

코드 검색

사용 예시 · Cmaj7 운지 읽기
악보에 Cmaj7이 나오면 코드 이름을 그대로 검색해 손가락 위치와 구성음을 확인할 수 있습니다.

  1. 검색창에 Cmaj7을 입력하고 코드 찾기를 누릅니다.
  2. 다이어그램은 왼쪽부터 6번 줄입니다. O는 프렛을 누르지 않고 치는 줄, X는 치지 않는 줄입니다.
  3. 예를 들어 6번부터 X–3–2–0–0–0으로 표시된 운지는 5번 줄 3프렛과 4번 줄 2프렛을 누르고, 3·2·1번 줄은 그대로 칩니다.

※ 이전과 다음으로 같은 코드의 다른 운지를 보고, 소리 듣기로 연주한 음과 비교해 보세요.

코드 판별

영상에서 본 손 모양이나 내가 연습한 운지가 무슨 코드인지 확인할 때 쓰는 기능입니다. 화면의 기타 지판에 어느 줄을 몇 프렛에서 누르는지 직접 표시하면, 그 운지에서 나는 음을 계산해 가능한 코드 이름을 보여줍니다.

사용 예시 · 5번 줄과 4번 줄의 2프렛만 눌렀을 때

  1. 시작 프렛을 1로 두고, 5번 줄과 4번 줄의 2프렛을 각각 누릅니다.
  2. 6번 줄과 3·2·1번 줄 위의 X를 눌러 O로 바꿉니다. X로 두면 그 줄은 판별에서 빠집니다.
  3. 이대로 여섯 줄을 치면 E·G·B 세 음이 납니다. 화면의 코드 후보에 Em(이 마이너)이 표시됩니다.

※ 여러 후보가 표시되며, 각 후보를 클릭하면 코드 검색으로 넘어갑니다.

메트로놈

템포는 40~240 BPM에서 슬라이더나 숫자 입력으로 조절할 수 있어요.

사용 예시 · 60 BPM에 맞춰 스트로크 연습하기

  1. 템포를 60 BPM으로 맞추고 시작을 누르세요.
  2. 추가 가운데를 지나며 클릭음이 날 때마다 기타 줄을 한 번씩 쳐보세요. 4박 중 첫 박은 더 강하게 들려요.
  3. 박자가 익숙해지면 BPM을 조금 올려보세요. 연습을 마치면 멈추기를 누르세요.

악보 키 변환

악보 속 코드가 어려워 카포를 끼우고 싶을 때.
키가 너무 높아서 한 키만 내리고 싶을 때.
악보 사진을 넣으면 연주하기 편한 코드로 바꿔줘요!

지판에서 카포 위치를 고르면 원래 키에 맞는 코드 모양으로 바뀝니다. 카포 없이 키를 낮추고 싶다면 카포 없음에서 −를 누르세요.

사용 예시 · 카포 2프렛으로 D키 곡 연주하기

1 / 4
1. 악보 이미지 불러오기
파일 선택클립보드에서 붙여넣기
또는 이미지를 여기에 끌어 놓으세요
2. 카포를 2프렛으로 옮기기
−카포 2+카포 없음에서 + 두 번
3. 악보에 표시된 코드 확인하기
카포 2프렛원래 키 D 유지
4. 인식되지 않은 코드 직접 추가하기
코드 직접 추가악보에서 빠진 코드 위치 선택
원래 코드Bm저장
  1. 파일을 선택하거나 악보 이미지를 업로드 영역에 끌어 놓습니다. 잘못 읽힌 코드가 있으면 악보에서 그 코드를 눌러 수정합니다.
  2. 지판에서 2프렛을 누르거나, 카포 없음에서 +를 두 번 누릅니다.
  3. 악보에 표시된 새 코드 모양을 확인하고, 실제 기타에도 카포를 2프렛에 끼운 뒤 연주합니다.
  4. 코드가 인식되지 않았다면 코드 직접 추가를 누르고, 악보에서 빠진 위치를 선택한 뒤 원래 코드 이름을 입력해 저장합니다.

※ 원래 코드가 D–A–Bm–G일 때, 카포를 2프렛으로 설정하면 C–G–Am–F가 표시됩니다.
