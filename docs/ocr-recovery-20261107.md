라벨에는 좌표가 없으므로 이미지별 행 순서와 출력 순서를 펼쳐 LCS로 문자열이 정확히 같은 발생 수를 셉니다. 반복·대소문자·괄호·슬래시는 그대로 비교합니다. 일치 사이의 불일치 구간에서 순서대로 쌍을 이루는 토큰은 오인식, 남은 참조는 누락, 남은 출력은 불필요한 검출입니다. 공간적 매칭이 아니므로 반복 주변에서는 정렬의 모호성이 있습니다.

## 현재 코드 재현

데이터와 공개 런타임 준비는 [2차 기록](ocr-refinement-20261106.md)의 모델과 재현 절차를 참고하세요. 아래는 최초 main과 최종 코드의 비교 명령입니다. 이전 기록의 `3aa998b`·`af8bacb`는 측정 당시의 로컬 스냅샷 식별자이며 아래 명령은 이 중간 스냅샷 없이 실행할 수 있습니다.

```sh
mkdir -p "$RUN_ROOT"
git show 87f8e841a2c5720a1b9f12708ce656f375c3b831:index.html > "$RUN_ROOT/main-before.html"
export NODE_PATH="$OCR_RUNTIME/node_modules" OCR_LANG_PATH="$OCR_RUNTIME" OCR_DEBUG=1 OCR_DIAGNOSTICS=1
for split in development evaluation; do
  OCR_APP_HTML="$RUN_ROOT/main-before.html" OCR_REGION_MODEL= node scripts/ocr-dataset.cjs "$DATA_ROOT/reviewed" "$DATA_ROOT" "$split" "$RUN_ROOT/main-$split"
  OCR_REGION_MODEL="$OCR_RUNTIME/rec.onnx" OCR_REGION_DICTIONARY="$OCR_RUNTIME/dict.txt" OCR_REGION_SECONDARY=1 node scripts/ocr-dataset.cjs "$DATA_ROOT/reviewed" "$DATA_ROOT" "$split" "$RUN_ROOT/final-$split"
done
for check in tests/*.cjs; do node "$check" || exit; done
# 같은 체크아웃을 localhost:8765에서 제공한 뒤 실행합니다.
OCR_REGION_MODEL="$OCR_RUNTIME/rec.onnx" OCR_REGION_DICTIONARY="$OCR_RUNTIME/dict.txt" node tests/browser/score.cjs
```

`OCR_RUNTIME`은 브라우저 검사에도 환경 변수로 전달하세요. `OCR_DIAGNOSTICS=1`은 영역·판독·기하·행 필터 단계별 비공개 출력을 추가합니다. 선택적인 `OCR_SAMPLE_IMAGE`·`OCR_SAMPLE_REPORT`도 저장소 밖의 개발 이미지와 결과 경로만 사용하세요.
