# 악보 OCR 실측 기록

2026-11-05. 브라우저 없이 Tesseract.js 5.1.1 / eng best_int, 앱과 같은 전처리·파서·병합 함수를 사용했습니다. 요청 한도는 2시간이었으나 작업이 초과되었습니다. 13라운드의 04 OCR 구간에 6411.5초가 기록되었으며, 중단 시점을 지키지 못했습니다. 원본 이미지는 `.ref`에만 두고 저장소에 포함하지 않습니다.

정답은 11장 이미지를 직접 보고 전사했습니다. 검은 인쇄 코드가 있는 06의 빨간 보조 필기는 제외합니다. 음악 기호 ♯/♭와 위첨자 숫자는 #/b와 기본 숫자로 정규화하며 괄호는 보존합니다. 09의 `Db(Bbm7)`와 `DbM7(Bb/D)`는 묶인 라벨 하나, 별도 간격이 있는 `(Eb/Db)`는 별도 라벨, 아래 줄 `(Cm7 Fm7)`는 `(Cm7)`와 `(Fm7)` 두 개로 셉니다. 11은 왼쪽 페이지 전체 → 오른쪽 페이지 전체 순서입니다.

평가는 줄별 발생 순서의 LCS로 중복 코드까지 셉니다. Precision = 일치 / 인식, Recall = 일치 / 정답. 틀린 이름은 FP와 FN 모두에 반영됩니다. 줄의 대략적인 y와 페이지 x 범위로 행을 구분하며, 정답을 실제 OCR 코드에 주입하지 않습니다. 기존 full-score는 이름과 원본 bbox 겹침으로도 대조합니다. 07의 마지막 두 행 y 표기를 시각 재검수해 바로잡은 뒤 저장된 원시 결과를 동일 기준으로 재평가했습니다.

```sh
NODE_PATH=/tmp/ocrt/node_modules OCR_LANG_PATH=/tmp/ocrt \
  node scripts/ocr-eval.cjs --all /tmp/ocr-round
```

최종 라운드는 13라운드의 실제 Tesseract 원시 판독을 재사용한 후처리 검증입니다. 이미지 전처리, OCR 호출 수·PSM·변형·영역 좌표가 모두 같음을 assert로 대조했습니다. 변경된 것은 마지막 중복 제거와 줄 필터뿐입니다. 최종 표의 초는 원시 판독 때의 시간을 그대로 기록하며 04의 긴 도구 대기를 포함합니다. 일반 OCR 성능 측정으로 해석하지 마세요.
